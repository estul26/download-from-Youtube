# Voices

Reference voices for option 6 (Chinese dubbing) live here, one folder each:

```text
voices/female-03/ref.wav      3-10 seconds of clean Mandarin speech
voices/female-03/voice.json   name, ref_audio, prompt_text, prompt_lang
```

Run `python3 fetch_voices.py` to pick free female voices from AISHELL-3
(Apache License 2.0). Everything in this folder except this README is ignored
by Git, so saved voices stay on your Mac.
